## 3) Conceptos (valor añadido vs lo que ya existe)

### 3.1 Breaker Block / MMXM

Ya detectas OB, FVG y BOS. **Añade**:
- **Inversión de rol**: el OB que **falló** pasa a ser soporte/resistencia tras CHOCH/MSS.
- **MMXM**: límite de **una sola mitigación**. Si vuelven a tocar la zona, el breaker muere.

### 3.2 OTE

Ya detectas entradas y estructura HTF. **Añade**:
- **Calidad de entry**: valida si la entrada está en la banda 62–79% de la pierna impulsiva.
- **No filtra entradas**: es **metadata** (observador/score).

### 3.3 SMT Divergence

Ya hay EQH/EQL/sweeps. **Añade**:
- Comparación **direccional sincronizada** entre activo objetivo y su correlato (mismo TF).
- Señal: activo hace HH y correlato hace LH (o viceversa).

## 5) Matemática (implementación exacta)

### 5.1 Fibonacci OTE

```python
OTE_FIB_LOW = 0.618
OTE_FIB_HIGH = 0.786

def ote_zone(swing_high: float, swing_low: float) -> tuple[float, float]:
    r = float(swing_high) - float(swing_low)
    if r <= 0:
        raise ValueError("rango no positivo")
    ote_high = float(swing_high) - OTE_FIB_LOW * r
    ote_low = float(swing_high) - OTE_FIB_HIGH * r
    return ote_low, ote_high

def is_ote_entry(entry_price: float, swing_high: float, swing_low: float, direction: int) -> tuple[bool, dict]:
    r = float(swing_high) - float(swing_low)
    if r <= 0:
        return False, {"ote_confirmed": False, "reason": "r<=0"}
    if direction == 1:
        ote_low = float(swing_high) - OTE_FIB_HIGH * r
        ote_high = float(swing_high) - OTE_FIB_LOW * r
    else:
        ote_low = float(swing_low) + OTE_FIB_LOW * r
        ote_high = float(swing_low) + OTE_FIB_HIGH * r
    confirmed = (ote_low <= float(entry_price) <= ote_high)
    meta = {"ote_confirmed": confirmed, "ote_low": ote_low, "ote_high": ote_high, "leg_range": r}
    return confirmed, meta
```

### 5.2 Breaker Block fuerza

```python
def strength(bars_since: int, zone_range: float, avg_range: float, max_bars: int = 80) -> float:
    recency = 1.0 - min(float(bars_since) / float(max_bars), 1.0)
    size_ratio = min(float(zone_range) / float(avg_range), 1.0) if avg_range > 0 else 0.5
    return float(np.clip(np.sqrt(recency * size_ratio), 0.0, 1.0))
```

Reglas:
1. Bearish OB roto: `close > top` → Bullish Breaker.
2. Bullish OB roto: `close < bottom` → Bearish Breaker.
3. MMXM: enter_price re-entra zona (una sola vez) desde `current_idx+1` en adelante → breaker inválido.

### 5.3 SMT Divergence

```
base_z = (close_base - mean_base) / std_base
corr_z = (close_corr - mean_corr) / std_corr

bullish  = base_z[-1] > base_z[peak] Y corr_z[-1] < corr_z[peak]
bearish  = base_z[-1] < base_z[trough] Y corr_z[-1] > corr_z[trough]
```

No normalizar en `z` cuando std ≈ 0.
