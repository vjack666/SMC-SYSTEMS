# MT5 Backtest Validation (F7)

## Purpose

Validate that trades generated by the Python backtest engine would match the
execution results of the real MT5 EA (`SMC_SYSTEMS_BRIDGE`). Instead of running
MT5 directly, we **simulate** the Bridge → EA pipeline in Python, applying
slippage, commission, and fill logic consistent with what the MQL5 EA would do.

## Architecture

```
Python Backtest Engine          MT5 Validation
┌───────────────────┐           ┌──────────────────────────┐

│  (generates trades)│  signals  │  (slippage, fills, com-  │
└───────────────────┘           │   mission, SL/TP hit)     │
                                └────────────┬─────────────┘
                                             │
                                ┌────────────▼─────────────┐
                                │  TradeComparator          │
                                │  Compare Python vs EA     │
                                └────────────┬─────────────┘
                                             │
                                ┌────────────▼─────────────┐
                                │  ReportGenerator          │
                                │  Text/JSON report output  │
                                └──────────────────────────┘
```

## Metrics Measured

| Metric | Description |
|--------|-------------|
| Win Rate | % of profitable trades |
| Profit Factor | Gross profit / gross loss |
| Total Net P&L | Net profit after commission |
| Total Pips | Cumulative pip gain |
| Max Drawdown | Peak-to-trough equity drop |
| Sharpe Ratio | Risk-adjusted return |
| Entry Price MAE | Mean absolute error of fill prices |
| Slippage Impact | Cost of simulated slippage |
| Delta (EA - Python) | Difference between engines |

## How to Run

```python
from smc_successor.backtest.validation.mt5_backtest_runner import MT5BacktestRunner, SlippageConfig
from smc_successor.backtest.validation.trade_comparator import TradeComparator
from smc_successor.backtest.validation.report_generator import ReportGenerator
from smc_successor.integration.mt5_bridge.schema import SignalMessage, SignalAction, OrderType

# 1. Load signals (from file or from engine output)
runner = MT5BacktestRunner(SlippageConfig(mode="fixed", fixed_pips=0.5))
signals = runner.load_signals_from_file("path/to/signals.json")

# 2. Run EA simulation
ea_results = runner.run(signals)

# 3. Load Python engine trades
python_trades = [...]  # from backtest/engine.py output

# 4. Compare
comparator = TradeComparator()
result = comparator.compare(python_trades, ea_results)

# 5. Generate report
gen = ReportGenerator()
text = gen.generate_text(result)
print(text)
gen.write_report(result)  # saves to reports/mt5_validation/
```
